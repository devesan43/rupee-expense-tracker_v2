# Rupee Expense Tracker V2

Complete Flutter V2 project.

Features:
- Manual categories
- Opening/current account balances
- Separate credit-card outstanding
- Category expense chart
- Budget vs actual
- Recurring expenses
- Search and date-range filtering
- Edit/delete transactions
- Excel export
- PDF report
- PIN lock
- Biometric-ready lock flow
- Improved SMS detection
- Transfers
- GitHub Actions APK build

Upload the whole project to GitHub. The workflow is `.github/workflows/build.yml`.
